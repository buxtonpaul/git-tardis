## Agent skills

### Issue tracker

Issues and PRDs for this repo live as GitHub issues. See `docs/agents/issue-tracker.md`.
When working on a new feature or issue use a seperate branch. Make sure that
there is something the user can test for each issue, and ask the user if they
are happy with the test artifact before closing the issue and merging the
branch.


### Domain docs

The engineering skills should consume this repo's domain documentation in a single-context layout. See `docs/agents/domain.md`.
