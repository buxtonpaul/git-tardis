# Git-tardis.
A tool for time travelling through your git repositories.

Allows you to move through your commit history tracing the evolution of your code.

Features :-
 - File viewer showing your current file with keys to navigate to the next/previous commit affecting the current line/function/file.
 - Inline rewrite. At a given commit make small inline changes to be applied as a git fixup.
 - Edit here - performs an interactive rebase pausing at the currently display commit to allow editing before continuing the rebase.
 - Neovim integration.
 - MacOS and Linux support.
 - TUI interface.

Simple Curl installation
